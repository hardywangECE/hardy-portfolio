Bake STEP models to .glb

Local dev-only tool (needs npm start running). Parses a STEP file with occt-import-js using the same settings as the live viewer, merges every solid into one mesh, exports a binary .glb, and saves it straight into assets/models/ via the dev server. Run this whenever you add or change a STEP file, then point that project's model field in js/data.js at the resulting .glb instead of the .step file — loads in well under a second instead of several seconds, since there's no STEP parsing left to do in the browser.
